# Project Rules

- Before modifying active codebase files or database records, always present a mock-up, generated image, or browser-preview demonstrating the proposed visual/functional changes first.
- Only write code or commit database updates once the user has reviewed the preview and explicitly approved applying the changes.
- If the user dislikes the proposed changes, do not write/apply them; iterate on the designs or plan based on user feedback.
- if the changes will affect uer permission and work flows and access rights must double check and inform user clearly about the changes and get the approval first
Use Frappe's standard built-in components and functionality for the implementation. Do not use external or out-of-the-box solutions.
