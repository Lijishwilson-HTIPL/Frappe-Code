  - The bench lives in WSL. The Bash tool runs WINDOWS Git Bash, so `bench` and
    `/home/paul` do NOT exist there. Prefix everything:

    with frappe.init(site="mysite.local"); frappe.connect().

        cd ~/frappe-bench && honcho run bash -c "cd sites && ../env/bin/python ..."
